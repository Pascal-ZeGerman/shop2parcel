# Phase 13.1 Plan 03: GmailCoordinator + ImapCoordinator — FIFO Trim + Persist at Poll End Summary

Both coordinator subclasses updated with symmetric seed-from-restored expression and end-of-poll FIFO-trim + `_pending_shipments` assignment + `_async_save_store()` call, completing the RED->GREEN cycle for all 6 Phase 13.1 tests.

## What Was Built

### Task 1: GmailCoordinator changes (commit c7e2891)

**Change 1 — Seed expression** (`gmail_coordinator.py` line 178):

Before: `current_data: dict[str, ShipmentData] = dict(self.data or {})`

After:
```python
current_data: dict[str, ShipmentData] = (
    dict(self.data) if self.data is not None else dict(self._restored_shipments)
)
```

**Change 2 — End-of-poll FIFO + save block** (inserted before `return current_data`, after the existing quota-expiry guard):

```python
if not debug_mode:
    trimmed = dict(current_data)
    while len(trimmed) > MAX_SUBMITTED_TRACKING_NUMBERS:
        oldest = next(iter(trimmed))
        del trimmed[oldest]
    self._pending_shipments = trimmed
    await self._async_save_store()
```

**Deviation (Rule 1 - Bug)**: Test helper `_setup_coordinator` in `tests/test_store_migration.py` applied OAuth2 patches only inside the setup `with` block. After setup returned, the patch was gone, so direct calls to `coordinator._async_update_data()` in tests hit the real OAuth2 infrastructure and raised `ValueError: Implementation not available`. Fixed by applying persistent `patch.start()` / `patch.stop()` patches registered to HA's shutdown event.

### Task 2: ImapCoordinator changes (commit 5382a93)

Identical symmetric changes applied to `imap_coordinator.py`:
- Line 163: same seed expression (`dict(self.data) if self.data is not None else dict(self._restored_shipments)`)
- Before `return current_data`: same `if not debug_mode:` FIFO-trim + `_pending_shipments` + save block
